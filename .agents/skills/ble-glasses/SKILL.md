# Web Bluetooth لنظارة «عين» الذكية

## المتطلبات والقيود
- `navigator.bluetooth` يعمل على **Chrome (أندرويد وحاسوب)** فقط، ويتطلب **HTTPS** وتفاعلاً صريحاً من المستخدم (نقرة زر).
- حالياً الاقتران معطّل في `js/views/ray.js` عبر العلم `BLE_HARDWARE_ENABLED = false` لحين اكتمال العتاد.

## بروتوكول HM-10 للنظارة
- الخدمة (Service UUID): `0000ffe0-0000-1000-8000-00805f9b34fb`
- الخاصية (Characteristic UUID): `0000ffe1-0000-1000-8000-00805f9b34fb`
- صيغة البيانات: المسافة تصل كـ **`uint16` بالسنتيمتر (little-endian)** ← `e.target.value.getUint16(0, true) / 100` (بالمتر).

## قواعد الموثوقية عند التفعيل
- عالج حدث انقطاع الاتصال (`gattserverdisconnected`) ومهلة انتهاء صلاحية القراءة: **عند انقطاع الاتصال أو توقف الإشعارات، توقف عن نطق أو تنبيه آخر مسافة معروفة** وأبلغ المستخدم بالانقطاع مرة واحدة.
- عند تحديث اسم جهاز BLE مستقبلاً، تجنّب ربطه باسم خاص بمدرسة أو أشخاص، ووحّد العلامة على «عين» (`namePrefix: 'Ain'`).
