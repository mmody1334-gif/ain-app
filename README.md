# عين — Ain

[![tests](https://github.com/mmody1334-gif/ain-app/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/mmody1334-gif/ain-app/actions/workflows/tests.yml)

تطبيق ويب (PWA) يعمل على الموبايل لمساعدة ذوي الإعاقة:

- **ترجمة لغة الإشارة** بالكاميرا ونطقها بصوت عربي فصيح، بيد واحدة أو بيدين.
- **الاستماع**: يحوّل الكلام المسموع إلى نص كبير لضعاف السمع.
- **رادار صوتي للكفيف**: الكاميرا الخلفية ترصد العوائق وتنبّه بالصوت والاهتزاز، مع تحديد الاتجاه (يمين / أمام / يسار).
- **غرف فورية** بين جهازين، وزر طوارئ يرسل الموقع.
- يعمل **بدون إنترنت** بعد أول فتح.

## الجودة

| ماذا نختبر | كيف |
|---|---|
| عدم الخلط بين الإشارات | المحرك الحقيقي على عينات لم يرها (4 طيّات): 0 كلمة خطأ |
| إشارات اليدين | اليد الثانية تتأخر حتى ثانية كاملة: كلمة واحدة صحيحة |
| مسافة الرادار | هندسة الكاميرا، الكف على العدسة، الممر الفارغ، شخص قريب |
| النطق | تشكيل الكلمات، لا قطع لجملة جارية إلا لخطر |
| الاهتزاز | نمط مختلف لكل مسافة، بلا اهتزاز في الجيب |
| خصوصية الغرف | أكواد غير قابلة للتخمين، والموقع يُمحى بعد 24 ساعة |
| سهولة الوصول | axe-core على كل الشاشات (فاتح وداكن): 0 مشكلة |

كل ذلك يعمل تلقائياً مع كل تعديل (شارة **tests** أعلاه).

## التشغيل محلياً

```bash
# الاختبارات
node --test tests/*.test.mjs

# فحص سهولة الوصول في متصفح حقيقي
npm i --no-save playwright axe-core && npx playwright install chromium
node tests/a11y-check.browser.mjs
```

التطبيق بلا خطوة بناء: افتح `index.html` من أي خادم ملفات ثابت.
